# Panel produktow Mazhi Sandbox

Wersja: 0.1.0

Prywatna aplikacja uruchamiana lokalnie, przeznaczona
do testowania integracji z Allegro Sandbox.

## Obecne funkcje

- Przygotowywanie i zapisywanie lokalnych szkiców ofert.
- Lokalna kontrola kompletności danych formularza.
- Przygotowana integracja odczytu kategorii Allegro,
  oczekująca na potwierdzenie rzeczywistego połączenia.

## Planowane funkcje

- Parametry produktów zależne od kategorii.
- Wystawianie i edycja ofert w środowisku testowym.
- Odczyt zamówień z konta testowego.

## Informacje o repozytorium

Repozytorium zawiera wyłącznie opis aplikacji.
Nie zawiera kodu źródłowego, danych konta,
kluczy API ani tokenów.
